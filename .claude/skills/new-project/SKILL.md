# 从模板实例化新项目

四个决策全部前置，缺任何一个都不开跑：

1. **项目名**：`^[a-zA-Z][a-zA-Z0-9_-]*$`。由用户给出；可依用途提议候选，确认后使用，不静默填入。
2. **语言**：`python` / `go` / `node` / `rust`。依用户请求与目标形态判断；两种都合理时附证据问一句（「这是个 Go 服务，用 go？」优于开放式提问）。
3. **分层变体**（`--arch`）：`cls`（classic 三层式，默认）或 `hex`（hexagonal 四层）。判据：小工具、CRUD 密集、技术栈统一 → cls；业务规则复杂多变、依赖需长期可替换 → hex。拿不准就用默认 cls，不为可能不会发生的复杂度付费；用户明确要四层/端口时用 hex。
4. **目标路径**：默认 `../<name>`，必须不存在或为空。已存在且非空时停下交还状态，不用破坏性命令腾地方。

**Done when**：四项各有一个用户确认过的值。

## 运行

在模板仓库根目录，或任意目录用绝对路径：

```bash
python /path/to/template/scripts/init.py --name <name> --lang <lang> --arch <cls|hex> --target <path>
```

Go 项目询问 `--module-path`（默认同项目名）。

**Done when**：命令退出 0，目标目录出现完整项目（骨架 + 测试 + docs + CLAUDE.md），且 CLAUDE.md 的「语言规则」段标题标注了所用变体。

## 收尾

- 报告生成结果与「初始化 10 分钟清单」（init 输出已含）。
- `--git` 仅在用户明确要求时加；默认不建仓、不提交。
- 实例化**不可重复运行**（无升级契约）：重做等于删目录重来，必须用户确认；改分层变体同理（没有跨变体迁移脚本）。

**Done when**：用户知道项目在哪、下一步做什么、且明白模板不会自动跟进该项目。
